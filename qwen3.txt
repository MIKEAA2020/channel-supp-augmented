## 1. Replace the false monotonicity proposition

The current proposition says that \(\alpha_r\) need not be monotone. That is false. Replace `Proposition~\ref{prop:monotonicity}` with the following two propositions.

```latex
\begin{proposition}[Monotonicity of the antipodal profile]
\label{prop:alpha-monotone}
For every nonempty metric space \(K\),
\[
\alpha_{r+1}(K)\le \alpha_r(K)
\qquad
\text{for all }r\ge0.
\]
Moreover, if \(K\) is compact,
\[
0\le \alpha_r(K)\le \frac12\operatorname{diam}(K).
\]
Consequently, once \(\alpha_D(K)=0\), one has \(\alpha_r(K)=0\) for every \(r\ge D\).
\end{proposition}

\begin{proof}
Let \(h:S^{r+1}\to K\) be continuous. Restrict \(h\) to an equatorial copy \(S^r\subset S^{r+1}\). The antipodal map on the equator is the ordinary antipodal map on \(S^r\). Hence
\[
\min_{u\in S^r} d(h(u),h(-u))
\ge
\min_{u\in S^{r+1}} d(h(u),h(-u)).
\]
Taking suprema over all continuous \(h:S^{r+1}\to K\) gives \(\alpha_r(K)\ge \alpha_{r+1}(K)\).

The diameter bound is immediate because
\[
d(h(u),h(-u))\le \operatorname{diam}(K)
\]
for every \(u\). The final statement follows from monotonicity.
\end{proof}

\begin{proposition}[Monotonicity of compression widths and certified envelopes]
\label{prop:width-monotone}
The Euclidean widths satisfy
\[
\delta_{r+1,\mathrm{inst}}^\diamond(A,B)
\le
\delta_{r,\mathrm{inst}}^\diamond(A,B),
\]
because an encoder into \(\mathbb R^r\) may be padded with a zero coordinate to give an encoder into \(\mathbb R^{r+1}\). Any certified lower envelope defined as a non-increasing piecewise function of \(r\) is likewise non-increasing. The upper envelope \(U_r^{(n)}(A,B)\), defined as the minimum over all admissible upper bounds available at dimension \(r\), is non-increasing in \(r\), because increasing \(r\) only enlarges the set of admissible bounds.
\end{proposition}
```

Delete the sentence:

> “\(\alpha_r\) need not be monotone in general…”

It is incorrect.

## 2. Replace the unsupported \(1/d_A\) corollary with a proved full-direction theorem

The current `Corollary~\ref{cor:general-1dA}` is not proved. Replace it with the following theorem. This is a rigorous upgrade and is one of the strongest repairs available.

```latex
\begin{theorem}[Full-direction antipodal sphere]
\label{thm:full-direction-sphere}
Assume \(n d_B>1\). Let \(D=D_{A,B}^{(n)}\). For every
\[
0\le r\le D-1,
\]
there exists a continuous map
\[
h:S^r\to \Inst_n(A,B)
\]
such that
\[
\|h(u)-h(-u)\|_{\diamond,\mathrm{inst}}
\ge
\frac{2}{d_A}
\qquad
\forall u\in S^r.
\]
Consequently,
\[
\alpha_r(\Inst_n(A,B))
\ge
\frac1{d_A}
\qquad
\text{for all }0\le r<D_{A,B}^{(n)}.
\]
\end{theorem}

\begin{proof}
Identify the direction space \(\mathfrak V_{A,B}^{(n)}\) with the real vector space of flag-block-diagonal Hermitian operators
\[
Z\in \Herm(A_0\otimes B\otimes C_n)
\]
satisfying
\[
\Tr_{B\otimes C_n}Z=0.
\]
Its real dimension is \(D=d_A^2(n d_B^2-1)\). Equip this space with any Euclidean norm and let \(S(\mathfrak V)\cong S^{D-1}\) be its unit sphere. It suffices to construct the desired map on \(S^{D-1}\); restriction to equatorial subspheres gives every \(r\le D-1\).

Fix the uniform flagged state
\[
\tau_0=\frac{I_B}{d_B}\otimes \frac{I_{C_n}}{n}.
\]
Let \(Z\in S(\mathfrak V)\). Write its Jordan decomposition
\[
Z=Z_+-Z_-,
\qquad
Z_+,Z_-\ge0,
\qquad
Z_+Z_-=0.
\]
Because \(Z\) is flag-block diagonal, functional calculus preserves flag-block diagonality, so \(Z_+\) and \(Z_-\) are flag-block diagonal. Since \(\Tr_{B\otimes C_n}Z=0\),
\[
\Tr_{B\otimes C_n}Z_+
=
\Tr_{B\otimes C_n}Z_-.
\]
Let
\[
t=\Tr Z_+=\Tr Z_->0,
\]
and define normalized states
\[
P=\frac{Z_+}{t},
\qquad
Q=\frac{Z_-}{t}.
\]
Then \(P,Q\) have orthogonal supports and share the same \(A_0\)-marginal
\[
\mu:=\Tr_{B\otimes C_n}P=\Tr_{B\otimes C_n}Q.
\]

If \(d_A=1\), the marginal constraint is automatic because \(A_0\) is one-dimensional and \(\Tr P=\Tr Q=1\). In that case set
\[
J^+(Z)=P,
\qquad
J^-(Z)=Q.
\]

Now assume \(d_A\ge2\). Put \(\lambda=1/d_A\). Since \(\mu\) is a state on \(A_0\), \(\mu\le I_{A_0}\). Hence
\[
\lambda\mu
=
\frac{\mu}{d_A}
\le
\frac{I_{A_0}}{d_A}.
\]
Define the correction state
\[
\nu
=
\frac{\frac{I_{A_0}}{d_A}-\lambda\mu}{1-\lambda}.
\]
Then \(\nu\ge0\) and \(\Tr\nu=1\). Define
\[
J^+(Z)
=
\lambda P+(1-\lambda)\nu\otimes\tau_0,
\]
\[
J^-(Z)
=
\lambda Q+(1-\lambda)\nu\otimes\tau_0.
\]
Both \(J^\pm(Z)\) are positive, flag-block diagonal, and have \(A_0\)-marginal
\[
\lambda\mu+(1-\lambda)\nu
=
\frac{I_{A_0}}{d_A}.
\]
Therefore each is the normalized flagged Choi operator of an instrument. Let \(h(Z)\) be the instrument corresponding to \(J^+(Z)\).

For \(-Z\), the positive and negative parts are interchanged:
\[
(-Z)_+=Z_-,
\qquad
(-Z)_-=Z_+.
\]
The scalar \(t\) and the common marginal \(\mu\) are unchanged. Hence the correction state \(\nu\) is unchanged, and
\[
h(-Z)=\mathcal I^-(Z),
\]
where \(\mathcal I^-(Z)\) has Choi operator \(J^-(Z)\).

The Choi difference is
\[
J^+(Z)-J^-(Z)
=
\lambda(P-Q)
\]
when \(d_A\ge2\), and equals \(P-Q\) when \(d_A=1\). Since \(P,Q\) are states with orthogonal supports,
\[
\|P-Q\|_1=2.
\]
Thus
\[
\|J^+(Z)-J^-(Z)\|_1
=
\frac{2}{d_A}
\]
for \(d_A\ge2\), and equals \(2\) for \(d_A=1\), which is also \(2/d_A\).

For any Hermiticity-preserving instrument direction \(\vec\Delta\), the instrument diamond norm dominates the trace norm of its normalized flagged Choi operator, because testing on the maximally entangled input state gives the Choi operator itself. Therefore
\[
\|h(Z)-h(-Z)\|_{\diamond,\mathrm{inst}}
\ge
\frac{2}{d_A}.
\]

Finally, the map \(Z\mapsto Z_+\) is continuous on Hermitian operators. The scalar \(t=\Tr Z_+\) is continuous and strictly positive on the compact unit sphere \(S(\mathfrak V)\), hence bounded away from zero there. Therefore \(Z\mapsto J^+(Z)\) is continuous, and so is the resulting instrument-valued map. Restricting to equatorial spheres \(S^r\subset S^{D-1}\) proves the claim for all \(0\le r\le D-1\).
\end{proof}
```

Then replace the old `Corollary~\ref{cor:general-1dA}` text with:

```latex

## 4. Replace the observable-sphere theorem with a clean version

The current `Theorem~\ref{thm:observable-sphere}` is too compressed and contains the undefined \(\beta_r^{\star,(n)}\). Replace it with the following.

```latex
\begin{theorem}[Observable antipodal sphere]
\label{thm:observable-sphere-clean}
Assume either
\begin{enumerate}
\item \(n\ge2\) and \(d_A\ge2\), or
\item \(n=1\), \(d_A\ge2\), and \(d_B\ge2\).
\end{enumerate}
Then
\[
\alpha_r(\Inst_n(A,B))=1
\qquad
0\le r\le d_A^2-2.
\]
\end{theorem}

\begin{proof}
First suppose \(n\ge2\). Fix a state \(\sigma\in\Sstate(B)\). For \(H\in\Herm_0(A)\), \(H\neq0\), define
\[
K(H)=\frac{H}{\|H\|_\infty},
\qquad
E_\pm(H)=\frac{I_A\pm K(H)}2.
\]
Then \(E_\pm(H)\ge0\) and \(E_+(H)+E_-(H)=I_A\). Define an instrument by
\[
\mathcal I^H_1(X)=\Tr(E_+(H)X)\sigma,
\]
\[
\mathcal I^H_2(X)=\Tr(E_-(H)X)\sigma,
\]
\[
\mathcal I^H_k(X)=0
\qquad(k\ge3).
\]
This is an instrument because each component is completely positive and trace-nonincreasing, and the sum is the replacement channel \(X\mapsto\Tr(X)\sigma\).

Because \(K(H)\) is Hermitian with operator norm one, it has an eigenvector \(|\psi\rangle\) with eigenvalue \(+1\) or \(-1\). If \(K(H)|\psi\rangle=|\psi\rangle\), then
\[
\Tr(E_+(H)|\psi\rangle\langle\psi|)=1,
\qquad
\Tr(E_-(H)|\psi\rangle\langle\psi|)=0.
\]
For \(-H\), the roles of \(E_+\) and \(E_-\) are reversed. Hence the flagged outputs for \(H\) and \(-H\) on the input \(|\psi\rangle\langle\psi|\) are
\[
\sigma\otimes |1\rangle\langle1|
\qquad\text{and}\qquad
\sigma\otimes |2\rangle\langle2|,
\]
which are orthogonal. Their trace distance is \(2\). Since the diameter of the instrument body is at most \(2\), the distance is exactly \(2\).

The map \(H\mapsto H/\|H\|_\infty\) is continuous on the Euclidean unit sphere in \(\Herm_0(A)\), whose dimension is \(d_A^2-1\). Therefore the construction gives a continuous image of \(S^{d_A^2-2}\) with antipodal distance \(2\). Equatorial restriction gives the result for all smaller \(r\).

For \(n=1\) and \(d_B\ge2\), choose two orthogonal states \(\sigma_+,\sigma_-\in\Sstate(B)\). Define a channel
\[
\Phi^H(X)
=
\Tr(E_+(H)X)\sigma_+
+
\Tr(E_-(H)X)\sigma_-.
\]
The same eigenvector witness gives orthogonal outputs \(\sigma_+\) and \(\sigma_-\), hence distance \(2\). The continuity argument is identical.
\end{proof}
```

Then insert this lemma, preferably before the appendix or in the replacement section:

```latex
\begin{lemma}[Join of an observable sphere with a replacement sphere]
\label{lem:observable-replacement-join}
Let
\[
O:S^a\to\Inst_n(A,B)
\]
be a continuous family with
\[
\|O(u)-O(-u)\|_{\diamond,\mathrm{inst}}=2
\]
for all \(u\), and suppose all flagged outputs of \(O(u)\) are supported in a flagged subspace \(W_O\).

Let
\[
R:S^b\to\RepInst_n(A,B)
\]
be a replacement-instrument sphere supported in a flagged subspace \(W_R\) orthogonal to \(W_O\), with
\[
\|R(v)-R(-v)\|_{\diamond,\mathrm{inst}}=2
\]
for all \(v\).

Then there exists a continuous map
\[
H:S^{a+b+1}\to\Inst_n(A,B)
\]
such that
\[
\|H(y)-H(-y)\|_{\diamond,\mathrm{inst}}=2
\qquad
\forall y\in S^{a+b+1}.
\]
\end{lemma}

\begin{proof}
Represent \(S^{a+b+1}\) as the unit sphere in
\[
\mathbb R^{a+1}\oplus \mathbb R^{b+1}.
\]
For \(y=(x,z)\), set
\[
\lambda=\|x\|_2^2,
\qquad
1-\lambda=\|z\|_2^2.
\]
If \(x\neq0\), set \(u=x/\|x\|_2\); if \(z\neq0\), set \(v=z/\|z\|_2\). Define
\[
H(y)=\lambda O(u)+(1-\lambda)R(v),
\]
omitting a term when its weight is zero. Convex combinations of instruments are instruments. Continuity at \(\lambda=0\) or \(\lambda=1\) follows because the omitted term has diamond norm bounded by its weight.

Because \(W_O\perp W_R\), the flagged output difference decomposes as an orthogonal direct sum. For every input state,
\[
\|\Delta H(y)\|_1
=
\lambda\|\Delta O(u)\|_1
+
(1-\lambda)\|\Delta R(v)\|_1.
\]
The replacement term has norm \(2\) independently of the input state. Choose an input state witnessing the antipodal distance \(2\) for \(O(u)\). Then the total norm is
\[
\lambda\cdot2+(1-\lambda)\cdot2=2.
\]
\end{proof}
```

This removes the undefined \(\beta_r^{\star,(n)}\) and gives the observable/join construction a rigorous home in the paper.

\begin{theorem}[Zero-error threshold]
\label{thm:zero-error-threshold-strong}

\delta_{r,\mathrm{inst}}^\diamond(A,B)=0

\begin{proof}

The instrument body becomes a compact convex set \(C\subset\mathbb R^{D_{A,B}^{(n)}}\). The encoder is the inclusion \(f(x)=x\), padded with zeros if \(r>D_{A,B}^{(n)}\). \label{cor:instrument-compression-best}
Assume \(n d_B>1\), and let \(Y\) admit a continuous injection into \(\mathbb R^r\). Every continuous encoder
\[
\operatorname{Enc}:\Inst_n(A,B)\to Y
\]
and every decoder
\[
\operatorname{Dec}:Y\to\mathfrak A_{A,B}^{(n)},
\]
with no regularity assumption on the decoder, satisfy

\sup_{\mathcal I\in\Inst_n(A,B)}
\|\operatorname{Dec}(\operatorname{Enc}(\mathcal I))-\mathcal I\|_{\diamond,\mathrm{inst}}

\]

\[
\delta_{r,\mathrm{inst}}^\diamond(A,B)=0
\qquad
\Longleftrightarrow

r\ge D_{A,B}^{(n)}.
\]
Moreover, for every \(r\ge D_{A,B}^{(n)}\), exact decoding may be chosen continuous.
\end{corollary}

(y_0,y_1)\longmapsto
\frac{\jmath(y_0)-\jmath(y_1)}

\coind F_2(Y)\le r-1.

\[

Now suppose
\[
L_{A,B}^{(n)}<q<D_{A,B}^{(n)}.
\]
We use the stronger of two antipodal constructions.

First, the centered ball of radius \(\rho_n\) around \(\mathcal I_*\) gives a continuous map \(S^q\to\Inst_n(A,B)\) with antipodal separation \(2\rho_n\). Since \(q<D_{A,B}^{(n)}=\dim\mathfrak V_{A,B}^{(n)}\), we have \(q+1\le D_{A,B}^{(n)}\). Choose a \((q+1)\)-dimensional subspace
\[
W\subseteq\mathfrak V_{A,B}^{(n)}
\]
and take the Euclidean unit sphere \(S^q\subset W\). Define
\[
h_{\rho}(u)
=
\mathcal I_*+
\rho_n\frac{u}{\|u\|_{\diamond,\mathrm{inst}}}.
\]
The denominator is nonzero on the Euclidean sphere, and finite-dimensional norm equivalence makes the radial normalization continuous. Theorem~\ref{thm:instrument-ball} ensures that the image lies in \(\Inst_n(A,B)\). The antipodal separation is \(2\rho_n\).

Second, Theorem~\ref{thm:full-direction-sphere} gives a continuous map

h_{\mathrm{dir}}:S^q\to\Inst_n(A,B)

with antipodal separation at least \(2/d_A\).

2\gamma_{A,B}^{(n)}.

\[

\quad\text{and}\quad
\operatorname{Enc}(h(-u))

u\longmapsto

For a topological space \(Y\), the deleted product
\[

\]
is a continuous equivariant map
\[
F_2(Y)\to S^{r-1}.
\]
Borsuk--Ulam then implies
\[
\coind F_2(Y)\le r-1.
\]
Hausdorffness is not needed to form the deleted product itself, but it is natural when latent spaces are compared with Euclidean codes or compact images.
\end{remark}

# 8.3 Replace the mixed-program proof in the exact no-programming theorem

Replace the proof of `Theorem~\ref{thm:no-programming-app}` with the following polished version.

```latex
\begin{proof}
For pure program states, the standard no-programming theorem
\cite{NielsenChuang1997} implies that distinct unitary channels require orthogonal program vectors. It remains to pass from pure to mixed programs.

Suppose
\[
\pi_U=\sum_j q_j |p_j\rangle\langle p_j|,
\qquad q_j>0,
\]
is a spectral decomposition of a program that evaluates the unitary channel
\(\mathcal U_U\). For every pure input \(|\psi\rangle\), linearity gives
\[
U|\psi\rangle\langle\psi|U^\dagger
=
\sum_j q_j\,
\Gamma\bigl(|p_j\rangle\langle p_j|\otimes|\psi\rangle\langle\psi|\bigr).
\]
Because \(\Gamma\) is completely positive and trace preserving, each summand
\[
\sigma_{j,\psi}
:=
\Gamma\bigl(|p_j\rangle\langle p_j|\otimes|\psi\rangle\langle\psi|\bigr)
\]
is a density operator. The left-hand side is a pure state, hence an extreme point of the convex set of density operators. Since every weight \(q_j\) is strictly positive, the convex decomposition can equal a pure state only if every summand equals that pure state:
\[
\sigma_{j,\psi}
=
U|\psi\rangle\langle\psi|U^\dagger
\qquad
\forall j,\ \forall |\psi\rangle.
\]

Fix \(j\). The map
\[
\Lambda_j(X)
=
\Gamma(|p_j\rangle\langle p_j|\otimes X)
\]
is a channel. The preceding paragraph shows that \(\Lambda_j\) agrees with \(\mathcal U_U\) on every rank-one projector. Rank-one projectors span the real vector space \(\Herm(E)\), so \(\Lambda_j=\mathcal U_U\) on \(\Herm(E)\) by real linearity. Complex linearity then gives equality on all of \(\Lin(E)\). Hence every pure program vector in the support of \(\pi_U\) induces the channel \(\mathcal U_U\) exactly.

Now apply the same argument to spectral decompositions of programs for two distinct unitary channels \(\mathcal U_U\) and \(\mathcal U_V\). The pure-state no-programming theorem implies that every positive-weight eigenvector of a program for \(\mathcal U_U\) is orthogonal to every positive-weight eigenvector of a program for \(\mathcal U_V\). Those eigenvectors span the respective supports, so
\[
\operatorname{supp}\pi_U
\perp
\operatorname{supp}\pi_V.
\]
A finite-dimensional Hilbert space cannot contain infinitely many mutually orthogonal nonzero subspaces, whereas a nontrivial system \(E\) admits infinitely many distinct unitary channels. This contradiction proves the theorem.
\end{proof}
```

This fixes the audit point about making the pure-to-mixed extension explicit.

# 8.4 Replace the approximate-program-dimension proof with a quantifier-clean version

Replace the proof of `Corollary~\ref{cor:program-dimension-diverges-app}` with the following.

```latex
\begin{proof}
Suppose the conclusion is false. Then the integer sequence \((m_j)\) has a bounded subsequence. Passing to that subsequence, still indexed by \(j\), assume
\[
m_j\le m_{\max}
\]
for all \(j\). Let \(M\simeq\mathbb C^{m_{\max}}\). For each \(j\), choose an isometry
\[
W_j:M_j\to M,
\]
and set
\[
P_j=W_jW_j^\dagger.
\]
Fix a state \(\tau_j\in\Sstate(M_j)\). Define
\[
\Lambda_j:\Lin(M)\to\Lin(M_j)
\]
by
\[
\Lambda_j(\eta)
=
W_j^\dagger P_j\eta P_jW_j
+
\Tr[(I_M-P_j)\eta]\tau_j.
\]
The first term is a compression channel onto the embedded copy of \(M_j\). The second term is a measure--prepare map associated with the positive effect \(I_M-P_j\), hence is completely positive. For \(\eta\ge0\),
\[
\Tr\Lambda_j(\eta)
=
\Tr(P_j\eta)+\Tr[(I_M-P_j)\eta]
=
\Tr\eta,
\]
so \(\Lambda_j\) is trace preserving. Thus \(\Lambda_j\) is CPTP. Moreover, for every \(\pi\in\Sstate(M_j)\),
\[
\Lambda_j(W_j\pi W_j^\dagger)=\pi.
\]

Define the extended processor
\[
\widetilde\Gamma_j
=
\Gamma_j\circ(\Lambda_j\otimes\id_E)
:
\Lin(M\otimes E)\to\Lin(E).
\]
Then \(\widetilde\Gamma_j\) is CPTP and preserves every channel originally programmed by \(\Gamma_j\): if \(\pi'\in\Sstate(M_j)\) programs a channel with \(\Gamma_j\), then the embedded state
\[
\pi=W_j\pi'W_j^\dagger
\]
programs the same channel with \(\widetilde\Gamma_j\).

The set of CPTP maps \(\Lin(M\otimes E)\to\Lin(E)\) is compact in finite dimensions. Passing to a subsequence, chosen independently of the target unitary \(U\), assume
\[
\widetilde\Gamma_j\to\Gamma
\]
in diamond norm.

Now fix a unitary channel \(\mathcal U_U\). By hypothesis, for each \(j\) there exists a program state
\[
\pi'_j(U)\in\Sstate(M_j)
\]
such that
\[
\|\Gamma_{j,\pi'_j(U)}-\mathcal U_U\|_\diamond
\le
\varepsilon_j.
\]
Such a state exists because \(\Sstate(M_j)\) is compact and the map
\[
\pi\mapsto \|\Gamma_{j,\pi}-\mathcal U_U\|_\diamond
\]
is continuous. Define the embedded states
\[
\pi_j(U)=W_j\pi'_j(U)W_j^\dagger\in\Sstate(M).
\]
Compactness of \(\Sstate(M)\) gives a further subsequence, depending on \(U\), such that
\[
\pi_j(U)\to\pi_U
\]
for some state \(\pi_U\in\Sstate(M)\). Along this further subsequence the processors still converge to the same limit \(\Gamma\). Continuity of the evaluation map
\[
(\widetilde\Gamma,\pi)\mapsto \widetilde\Gamma(\pi\otimes\cdot)
\]
in diamond norm therefore gives
\[
\Gamma(\pi_U\otimes\cdot)=\mathcal U_U.
\]

Since \(U\) was arbitrary, the single finite-dimensional processor \(\Gamma\) exactly evaluates every unitary channel on \(E\), contradicting Theorem~\ref{thm:no-programming-app}. Hence no bounded subsequence of \((m_j)\) exists. Because \((m_j)\) is an integer-valued sequence, this is equivalent to
\[
m_j\to\infty.
\]
\end{proof}
```

This makes the quantifier structure explicit:

1. a processor subsequence is chosen first, independently of \(U\);
2. program states are chosen for each fixed \(U\);
3. a further state subsequence may depend on \(U\);
4. the limiting processor is common to all \(U\).
