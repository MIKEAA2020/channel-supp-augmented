## 2. The route (the integral lift of the G–J transgression machine)

Guerra–Jana compute `H*(Fl_n/Σ_n)` via the Serre SS of
`U(n) → Fl_n/Σ_n → BN(n)` with the Chern-class transgressions
`d_{2k}(z_{2k−1}) = f*(c_k)`. The wave lifts that mechanism to the cyclic
intermediate quotient with **integral** coefficients:

   `K = T³ ⋊ ⟨σ⟩ ⊂ U(3)` the cyclic monomial subgroup (the c-orbits in
   `Fl = U(3)/T³` are exactly the right K-cosets).

2. **The Borel fibration.** `U(3) → EU(3)×_K U(3) → BK` with total ≃ `B`,
   exhibited as the **pullback of the universal fibration along
   `Bι: BK → BU(3)`** — so the Serre SS transgressions are the pulled-back
   universal ones (Borel's classical `d_{2k}(z_{2k−1}) = c_k`, cited
   MilnorStasheff1974 + the new HatcherSS bibitem; validated on the lens
   model case):
   `d_2(z_1) = ι*c_1`, `d_4(z_3) = ι*c_2`, `d_6(z_5) = ι*c_3`.

3. **H\*(BK;Z) by hand.** The Serre SS of `BT³ → BK → BC₃` **collapses**
   (every differential from a nonzero term lands in a zero term: `r` even
   forces odd q-degree; `r` odd forces odd positive p-degree — the parity +
   permutation-module argument). Free part
   `Z[σ₁,σ₂,σ₃] ⊕ Δ·Z[σ₁,σ₂,σ₃]` (the orbit-sum module argument +
   Δ² = the classical discriminant); torsion `τ^k·σ̄₃^a` in bidegrees

   `τ·f = [coefficient of (χ₁χ₂χ₃)^{d/3} in f, mod 3]` — hence
   `τσ₁ = τσ₂ = τΔ = τσ₁³ = 0` while `τσ₃ ≠ 0`, `τ² ≠ 0`, `τ³ ≠ 0`.

   `ι*c_2 = σ₂ + 2τ²`; `ι*c_3 = σ₃`. The torsion constant `ε = 2` is pinned

   `τ² ↦ u²`) together with the Chern classes of the **regular
   representation** `1 ⊕ ω ⊕ ω²`: `c₁ = 3u = 0`, `c₂ = 2u²`, `c₃ = 0`.

5. **The crux.** In total degree 4 the incoming images into the `(4,0)` slot

   an infinite-order element. So `[τ²] ≠ 0` in
   `E_∞^{4,0} = (Zσ₂ ⊕ Z/3·τ²)/⟨σ₂ + 2τ²⟩ ≅ Z/3`.

6. **The edge.** The Serre-SS edge is the projection pullback = the
   classifying map `γ: B → BK` of the principal K-bundle; the intermediate

7. **The by-products.** The same run gives the whole tuple:
   `H² = Z/3⟨x⟩`, `H³ = Z/3⟨τz₁⟩`, `H⁵ = Z/3⟨τ²z₁⟩` (the rival `τz₃` class

**The two-worlds decision in `lem:flag-cohomology`** is now closed by hand:
